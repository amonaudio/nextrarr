2 · Conferma eliminazione artwork

Proposta per il dialogo di conferma (uguale per tutte e tre le varianti). Il file viene eliminato dal disco solo dopo la conferma. Nome file ben visibile, azione distruttiva in rosso, annulla in evidenza.

Eliminare questo artwork?

Il file verrà rimosso definitivamente dalla cartella del media.

clearart.png

Operazione non reversibile (se non hai un backup).

Il backend deve validare il filename (niente path traversal) e cancellare solo file dentro la cartella del media.

Dopo l'eliminazione: refresh della sola colonna locale + toast “Artwork eliminato”.

Se il file è usato come poster principale, il media card tornerà al poster remoto/N/A al prossimo refresh.
